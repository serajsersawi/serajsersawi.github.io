# alsersawi.space

Personal website of Sarraj Alsersawi — music & engineering.

- Hosted free on **GitHub Pages** from the `main` branch of this repo.
- Custom domain **alsersawi.space** (bought at Namecheap). The `CNAME` file
  tells GitHub the domain — don't delete it.
- DNS at Namecheap → Advanced DNS: four `A @` records
  (185.199.108–111.153) and `CNAME www → serajsersawi.github.io.`
- Any push to `main` goes live in ~1 minute.
- Plain HTML/CSS, no build step. `index.html` is the home page.
- This repo is **public** — never commit passwords or private files.
